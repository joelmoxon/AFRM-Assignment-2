The Aircraft Fuel and Range Management (AFRM) application is a C# console based prototype to support flight planning activities. It provides an indication of fuel sufficiency for a proposed flight, based on input parameters. 

**Development Environment and Dependencies**

- **Language:** C#
- **IDE:** Visual Studio
- **Framework:**.NET 10
- **Target platform:** x64
- **Dependencies:** Standard .NET libraries with no additional third-party packages.

Project configuration and build settings are defined in the .csproj file contained in the GitHub repository.

**Getting Started**

1. Install Visual Studio with .NET 10 SDK.
2. From the GitHub repository, select the green Code button and download the zip file.
3. Extract the Zip file.
4. Open AFRM Prototype.slnx in Visual Studio.
5. Build the solution.
6. Run the application.
7. The application will then launch in a console window and prompt the user for the required flight inputs.
8. Once all inputs have been successfully entered, the console will provide an indication of fuel sufficiency.
